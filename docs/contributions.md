# Guía de Contribuciones - Equipo Dinamita

## Cómo Contribuir

### 1. Crear una rama
```bash
git checkout -b feature/nombre-de-la-caracteristica
```

### 2. Hacer cambios
- Mantener la estructura del proyecto
- Seguir las convenciones de codificación en C++
- Agregar comentarios documentados

### 3. Commit
```bash
git commit -m "Descripción clara del cambio"
```

### 4. Push
```bash
git push origin feature/nombre-de-la-caracteristica
```

### 5. Pull Request
- Crear PR en GitHub
- Describir los cambios realizados
- Solicitar revisión de compañeros de equipo

## Estándares de Código

- Usar nombres descriptivos para variables y funciones
- Documentar clases y métodos públicos
- Mantener funciones pequeñas y especializadas
- Seguir el estilo de código del proyecto
